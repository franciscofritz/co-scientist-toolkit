# {{PROJECT}} facts registry

The project's settled facts, each with its current value and the source that states it. When a fact
changes, update its row; don't write the value somewhere new. This file is an index to the sources, not
evidence: check the source a row names before using a value in anything outward.

Source: an email (date, sender, subject), a document path and section, a transcript and timestamp, or a
results directory and commit. Paths are relative to the project root.

Status: `confirmed` (a primary source states it and the value was checked against it on the date
given), `claimed` (someone said so, not verified), `derived` (only a summary, note or earlier session
states it), `open` (needed or asked, no answer found), `unresolved` (sources disagree; see Conflicts).
